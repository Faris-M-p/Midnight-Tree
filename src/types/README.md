# src/types/

TypeScript models that match MidnightApi JSON.

| File | Purpose |
|------|---------|
| `api.ts` | Common `ApiResponse` / `ApiErrorItem` envelope |
| `auth.ts` | Register / login payloads |
| `member.ts` | Members list, profile, create, nested tree |

UI-only models (`FamilyMember` for cards) live in `src/types.ts`.
