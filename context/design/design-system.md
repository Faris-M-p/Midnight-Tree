# Design system

## Typography

Inter (or Next font equivalent). Consistent sizes/weights. Avoid decorative display fonts.

## Color

- Light: white page/surfaces, neutral grey borders, near-black text, one restrained accent
- Dark: dark page + slightly elevated surfaces, readable contrast, no white cards

## Components

Prefer simple buttons, inputs, dialogs, side panels. Tree cards compact (name, avatar placeholder, year, deceased mark).
